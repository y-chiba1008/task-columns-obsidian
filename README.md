# Dated Notes Table

Obsidian のノートを「日付 × フォルダ」の表で一覧するカスタムビュープラグインです。

## コンセプト

Vault 内の Markdown ノートを、次の軸でマトリクス表示します。

| 軸 | 意味 |
| --- | --- |
| 日付 | フロントマターの `datetime` から得た日付。日付のないノートは表下部の「日付なし」に集約 |
| フォルダ | 対象フォルダ直下のサブフォルダ |
| ノート | その日付・そのフォルダに属するノート |

各交点のノートは日時順（未設定は後ろ）、同日時ならタイトル順で並びます。タイトルをクリックすると該当ノートを開きます。

日付は仮想スクロールで前後に無限に伸ばせるため、カレンダーのようにスクロールしてノートの配置を俯瞰できます。

## 想定するノートの置き方

1. 設定で **Target folder**（例: `Notes`）を指定する
2. その直下にグループ用フォルダを置く（例: `仕事`, `プライベート`）
3. 各フォルダ内に Markdown ノートを置く
4. ノートのフロントマターに `datetime` を書く（任意）

```yaml
---
datetime: 2026-08-22T10:00:00
---
```

## 主な機能

- **Dated notes table** … 上記マトリクスのカスタムビュー
- コマンド **Open view** / リボンからビューを開く
- Vault の作成・削除・リネーム・メタデータ変更に追従して表を更新
- **Excluded folders** … 表から除外するフォルダをパスで指定（1行1パス）

## 設定

| 項目 | 内容 |
| --- | --- |
| Target folder | 表の対象となるルートフォルダ（Vault 相対パス） |
| Excluded folders | 除外するフォルダ（改行区切り）。一致するフォルダとその配下は非表示 |

## 開発

```bash
pnpm install
pnpm run dev    # ウォッチビルド
pnpm run build  # 本番ビルド
```

成果物 `main.js` / `manifest.json` / `styles.css` を Vault の `.obsidian/plugins/dated-notes-table/` に配置して利用します。
